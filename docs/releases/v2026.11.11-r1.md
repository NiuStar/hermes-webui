# v2026.11.11-r1

## Fixed

- Docker Agent update checks deepen a commit-only shallow history once when an older baked revision is absent, while retaining exact Release/tag and ancestor validation. Detection and image readiness remain separate.
- Agent image preparation no longer inherits the deleted managed dependency override from a prior release. The v0.23.1 build applies upstream's own Pillow 13 security override only for its exact source commit and pyproject SHA256, preserving upstream source and retaining dependency/image codec checks.

## Release contract

This release targets **linux/amd64 only**; no ARM64 runtime acceptance is claimed.
The release image is prepared on the approved builder. A source tag does not
create a GitHub Release until the full source suite and a fresh registry pull's
runtime/tool-loop, platform, source-file hashes, version and revision checks pass.
The downloadable `release-image.json` binds the Docker repository and immutable
digest to the exact WebUI and Agent commits. Docker Hub `latest` is not changed.

Production installation/restart is a separate operator action. Publication does
not switch the currently running container, updater, ports, mounts or state.
